# Nazifa Maliha — AI & Business Portfolio

An interactive, responsive portfolio for AI-in-business research, analytics, and enterprise strategy work.

## Open in VS Code

Open this folder in VS Code, then preview `dist/index.html` with the Live Server extension or any static web server.

## Files to edit

- `dist/index.html` — portfolio copy and project cards

## GitHub

The site uses plain HTML, CSS, and JavaScript, so it can be hosted directly with GitHub Pages. Push the folder to a GitHub repository, then publish the `dist` directory with your preferred Pages workflow.
